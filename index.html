High-Yield Exam Cheat Sheet

⚡ Must-Remember Key Notes
  • • BIOS & CMOS: The firmware is modified in the BIOS setup, and its settings are stored in the CMOS.
  • • CPU: Central Processing Unit (ALU = math/logic, CU = control/flow, Registers = fast memory).
  • • RAM: Random Access Memory (volatile temporary workspace; clears when power turns off).
  • • Storage Speed: Solid-State Drives (SSDs) use flash memory with no moving parts and are faster than magnetic drives (HDDs).

1. IPOS Cycle & Limitations

Input → Processing → Output → Storage.
Computers have Zero IQ and follow GIGO (Garbage In, Garbage Out).
Classification: Supercomputer → Mainframe → Minicomputer → Microcomputer. Hybrid computers process both Analog & Digital data.

2. Computer Generations

1st: Vacuum Tubes • 2nd: Transistors
3rd: Integrated Circuits (ICs) • 4th: Microprocessors (VLSI)
5th: ULSI & Artificial Intelligence

3. Semiconductors & Integration

Silicon/Germanium conductivity sits between conductors and insulators, controlled via doping (N-type/P-type).
Transistors act as electronic switches (1 = ON, 0 = OFF). Modern CPUs use VLSI / ULSI (millions–billions of transistors).

4. Binary Math Rules

Add: 1 + 1 = 10₂ (write 0, carry 1)
Add: 1 + 1 + 1 = 11₂ (write 1, carry 1)
Sub: 0 - 1 = 1 (borrow 1 from next bit = +2 in base 2)
